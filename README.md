## About CacheerPHP

CacheerPHP is a framework-independent cache library for PHP. It provides one API
for local and shared caches, with optional [monitoring](https://cacheerphp.com/docs/v6/en/cacheer-monitor/)
to help you understand how your cache behaves.

- [File, database, Redis, and in-memory stores](https://cacheerphp.com/docs/v6/en/api/drivers/).
- [Scoped invalidation](https://cacheerphp.com/docs/v6/en/guides/scopes/) and [tags](https://cacheerphp.com/docs/v6/en/tutorials/example-10-tagging/).
- [Stampede protection](https://cacheerphp.com/docs/v6/en/guides/remember-and-locks/) and [stale-while-revalidate](https://cacheerphp.com/docs/v6/en/guides/stale-while-revalidate/).
- [Tiered caching](https://cacheerphp.com/docs/v6/en/guides/tiered-caching/) and [automatic failover](https://cacheerphp.com/docs/v6/en/guides/resilient-store/).
